## 自动刷本边界

`scripts/farm_ember.py` 与 `cv/` 是旧原型和行为参考，不是新的通用执行器。旧原型只支持固定场景和部分作业语义，与桌面 UI 没有接通。

在新执行器、桌面运行桥接和实机验收完成前：

- 不把桌面运行按钮视为真实自动刷本入口。
- 不把离线回放通过等同于实机稳定。
- 不宣称支持任意作业、任意副本或日服/台服。
- 当前核心会在运行前拒绝需要补刀策略、选卡信息不足或含二次选择的作业；现有《娄希、娄希、奥伯龙》需等 #6 才能完整运行。
- 真实感知已提供图库内助战从者/概念礼装身份；普通指令卡使用 Atlas `commands` 原图识别从者，并独立识别卡色和助战标记，同名从者通过编译编队消歧。图库缺失或特征证据不足时保持未知，战斗回合边界仍是缺口，脚本化场景通过不等于真实作业可运行。
- 2026-11-21 实机短链路使用人工确认边界的测试适配器，已验证两次从者技能、攻击及选卡页安全停止；这不是完整实机验收或稳定性证明。
