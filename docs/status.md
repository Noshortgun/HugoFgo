## 自动刷本边界

`scripts/farm_ember.py` 与 `cv/` 是旧原型和行为参考，不是新的通用执行器。旧原型只支持固定场景和部分作业语义，与桌面 UI 没有接通。

在实机验收完成前：

- 桌面运行按钮已能启动执行器，但未经实机验收不得视为稳定或已交付。
- 不把离线回放或假运行通过等同于实机稳定。
- 不宣称支持任意作业、任意副本或日服/台服。
- 当前核心已在脚本化回放中接入全局/按面补刀策略、同名从者槽位优先级、卡色/暴击率/克制判据、计划宝具卡位保留和未清场后的后续回合；手牌不足或信息不确定时安全停止。含二次选择的作业仍会在运行前拒绝。
- 真实感知已提供图库内助战从者/概念礼装身份；普通指令卡使用 Atlas `commands` 原图识别从者，并独立识别卡色和助战标记，同名从者通过编译编队消歧。真实帧尚未输出指令卡暴击率与克制/抵抗，因此策略选卡仍会安全停止；战斗回合边界也仍是缺口，脚本化场景通过不等于真实作业可运行。
- 2026-11-21 实机短链路使用人工确认边界的测试适配器，已验证两次从者技能、攻击及选卡页安全停止；这不是完整实机验收或稳定性证明。
