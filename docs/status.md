## 自动刷本边界

`scripts/farm_ember.py` 与 `cv/` 是旧原型和行为参考，不是新的通用执行器。旧原型只支持固定场景和部分作业语义，与桌面 UI 没有接通。

在新执行器、桌面运行桥接和实机验收完成前：

- 不把桌面运行按钮视为真实自动刷本入口。
- 不把离线回放通过等同于实机稳定。
- 不宣称支持任意作业、任意副本或日服/台服。
