# 使用指南

本指南只介绍当前版本已经可操作的流程。桌面 UI 已接通 Python 执行器、实时运行面板和真实历史记录，但尚未完成实机验收；详见 [当前状态](status.md)。

## 1. 启动与资源准备

按 [README](../README.md#快速开始) 安装依赖并启动开发环境。首次克隆后先下载资源：

```bash
npm run resources:update
```

资源来自 Atlas Academy，需要联网。图库和原始元数据保存在本地，不随仓库分发。后续可使用：

```bash
npm run resources:check    # 检查远端版本
npm run resources:update   # 增量下载新增、变更或损坏的文件
npm run resources:verify   # 按 SHA-256 校验本地资源
```

在 `npm run tauri dev` 启动的桌面版中，可以通过资源中心选择国服、日服或台服，并执行检查更新、增量更新、校验与完整校准。每个区服使用独立的 `data/<区服>/` 目录；完整校准用于低频同步旧元数据，日常更新优先使用增量更新。浏览器预览只显示本地资源状态，不执行任务。

## 2. 编队与作业编排

1. 在编队页选择六个槽位的从者、概念礼装和御主礼装。
2. 标记助战位，并按需要指定助战从者、概念礼装或冠位条件。
3. 打开战斗编排，按面和回合添加技能、御主技能、换人、目标切换与攻击。
4. 配置宝具卡序、固定卡序或补刀策略。
5. 在作业面板保存当前作业，或导出 JSON 备份。

作业保存为 `jobs/` 下的 JSON 文件。桌面版由壳负责保存、读取和删除；开发期使用项目内 `jobs/`，打包后使用应用数据目录。浏览器预览只读，不能保存或删除。字段说明见 [作业格式](job-format.md)，完整示例见 `examples/sample-job.json`。

## 3. 导入作业

作业面板支持两种导入方式：

- 粘贴 Chaldea 分享链接或 Team ID，然后读取。
- 选择本地 HugoFgo 作业 JSON 文件。

Chaldea 导入需要联网。导入后应检查编队、技能目标、宝具卡序和选卡策略，再保存或导出。

## 4. 设备预览

设备功能只在 `npm run tauri dev` 启动的桌面版中可用：

1. 启动安卓模拟器并启用 adb 连接。
2. 在设备面板点击“检测设备”，选择状态为 `device` 的设备。
3. 读取分辨率和 DPI，再截取画面确认识别对象。
4. 如需测试坐标，使用测试点击功能。

测试点击会向模拟器发送真实输入，不要在未知画面或涉及道具消费的页面试点。点击截图也会触发坐标测试。

新执行器仅支持精确 16:9 横屏且不低于 1280×720 的设备。其他分辨率会被拒绝，不进行盲目缩放点击。adb 可通过 `HUGOFGO_ADB` 指向本机 `adb.exe`。

## 5. 启动运行

1. 在“设置与资源”中检测并选择 adb 设备。
2. 设置连续出击场数与 AP 恢复白名单。
3. 保存当前作业，然后在编队页点击“开始”。
4. 运行面板显示执行器的真实画面、面、回合、动作、耗时、恢复消耗与日志目录；点击“停止”后壳会等待执行器在动作边界发送终端事件，30 秒仍未确认时才异常终止整个进程树。

浏览器预览不能启动执行器，按钮会禁用并显示原因。桌面联调可先使用不接触模拟器的假运行：

```bash
HUGOFGO_FAKE_RUN=1 VITE_HUGOFGO_FAKE_RUN=1 npm run tauri dev
```

假运行仍读取所选作业并发送与真实运行相同格式的 JSON Lines 事件，用于验证启动、面板推进和停止；它不代表实机识别或战斗已经通过验收。

## 6. 查看运行记录

在“运行记录”中查看每次真实运行的作业、设备、区服、起止时间、耗时、完成场数、结果与恢复道具消耗。完成、手动停止和失败分别显示；失败原因随记录保存。点击“定位日志与失败截图”可查看 `events.jsonl` 和已保存失败帧的路径，完整证据仍按次保存在 `logs/farm/<时间戳>/`。

开发期桌面壳与直接运行的 Python 执行器都写入项目 `logs/run-history.jsonl` 和 `logs/farm/<时间戳>/`；安装版写入应用数据目录的 `logs/`。关闭并重启应用后仍可查询。浏览器预览不读取或生成历史记录，会明确提示改用桌面版。

## 7. 故障排查

| 现象 | 处理方式 |
| --- | --- |
| 从者或礼装图片缺失 | 运行 `npm run resources:update`，再用 `npm run resources:verify` 校验 |
| 资源更新失败 | 检查 Atlas Academy 与 GitHub 的网络连接，保留命令输出后重试 |
| 作业无法保存或资源按钮无响应 | 改用 `npm run tauri dev`；浏览器预览只读，桌面壳负责作业读写与资源任务 |
| 没有发现设备 | 启动模拟器，确认 adb 能列出设备，并检查 `HUGOFGO_ADB` 路径 |
| 设备显示 `offline` 或 `unauthorized` | 重新连接 adb，并在模拟器中确认 USB 调试授权 |
| 分辨率被拒绝 | 将模拟器改为精确 16:9 横屏，且不低于 1280×720 |
| Python 依赖检查失败 | 按 README 创建 `cv/.venv` 并安装 `cv/requirements.txt` |
| 浏览器中设备功能不可用 | 改用 `npm run tauri dev`；浏览器预览不提供设备命令 |

自动执行相关故障必须保留日志和截图，并按 [测试与验收](testing.md) 补充回放用例。
