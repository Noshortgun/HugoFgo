# 计划偏离进入独立的计划外自动战斗，而不是直接停止

Status: accepted（2026-11-24 与用户确认）

## Context

自动刷本希望用户省心。换人、退场补位、毅力、敌人行动等都可能让实际战斗不再符合作业预期。过去遇到无法按计划执行的动作时，仅靠“补刀选卡”或直接安全停止，前者不会主动使用技能和宝具，后者会因为并非危险的小偏差中断整轮刷本。

补刀策略的目标是“作业基本正常，只是没清场”，与“原作业已经失效，需要独立打完当前场”不是同一种问题。

## Decision

计划偏离本身不是停止理由。执行器只检查下一个计划动作能否安全执行：行动从者在场、所需目标在场、所需技能／宝具／换人控件确认可用。能够继续就继续原作业。

原动作无法执行时，记录偏离原因，并在当前场进入**计划外自动战斗**：

- 按前排从左到右、每人一至三技能使用指定从者可用技能。
- 需要选择己方目标的技能释放给最左存活指定从者；没有可用指定目标则跳过。
- 技能处理后优先使用确认可用的宝具，指定从者宝具优先于空槽位任意从者宝具；没有可用宝具再选择普通卡。
- 空槽位任意从者只自动使用宝具和普通卡，不主动释放技能。
- 不套用补刀的 `allowNp` 与固定宝具卡位。

进入时发出一次非阻塞提示，说明原因并明确“仅当前场自动、下一场恢复作业”。提示不暂停运行、不要求确认。事件与运行状态持续记录。下一场恢复原始作业与初始编队状态。

画面、从者或安全操作目标无法确认时仍安全停止。

## Consequences

- 小偏差不会再无条件终止整轮刷本，但计划动作被跳过的原因必须可追溯。
- 补刀策略与计划外自动战斗需要分别实现和测试，不能共用一套“只选卡”的行为。
- 计划外自动战斗不保证最优技能顺序或技能效果；它只在可确认的操作范围内尽量完成当前场。
- 中途启动无法还原此前换人和补位历史、但能确认当前战斗画面时，也进入该模式打完当前场。

## Considered Options

- **计划偏离直接安全停止**：实现简单，但违背用户希望省心自动刷本的需求，未采用。
- **计划偏离继续只用补刀选卡**：能选卡但不会主动使用技能与宝具，无法应对原计划失效，未采用。
- **跳过无法执行的动作继续后续计划**：会让计划动作被静默遗漏，且后续动作可能基于错误场上状态，未采用。
