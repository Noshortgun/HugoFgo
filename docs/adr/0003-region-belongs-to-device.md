# 区服属于设备，图库与识别配置按区服隔离

Status: accepted（2026-11-19 与用户确认）

产品要支持国服、日服、台服。区服定义为设备的属性：一台模拟器装的是哪个服，就在设备配置里选哪个服。作业不带区服，可跨服分享（从者 ID 一致）。

## Consequences

- 图库与资源清单按区服分目录各自缓存，切换区服不重下。
- 识别配置（OCR 语言、锚点文案、模板）按区服加载；缺配置时报"该区服未支持"，不允许误识别后继续。
- 首期只交付国服，日服与台服各自需要素材采集与实机验收，不能靠改配置宣称支持。
- 设备配置必须显式给出区服；缺失时报可操作错误，不允许静默按国服运行。

## Considered Options

- **区服属于作业**：会让同一份编队作业无法跨服复用，且无法解释"同一台设备上换作业"的场景。
