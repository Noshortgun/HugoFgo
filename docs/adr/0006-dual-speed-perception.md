# 双速感知：同步视觉快路径与后台按需 OCR

Status: accepted（2026-11-20 经原型与最小实机闭环验证；2026-11-21 随 #16 合并落地）

感知拆成两条路径。同步快路径禁止调用 OCR、网络和按次付费服务，只用区域化模板、颜色、边缘与布局证据，输出基页、版式变体、覆盖层、控件坐标和可操作性；后台 OCR 只按需补充 NP、面/回合、AP、敌人数量等字段，结果绑定帧哈希与请求 ID，画面已变则只进缓存、不驱动动作。

## Consequences

- 全图 OCR 实测约 1.5–3.3 秒，不能进入高频状态判定；`read()` 全程不调用 OCR。
- 执行器不能把“识别到页面”等同于“现在可以点击”；动作前的连续稳定确认属于执行器（#17），不在识别器内推进作业。
- 可操作性独立于基页：`battle` 不代表攻击按钮可用，`card` 不代表仍能选卡；`unknown / loading` 不输出控件。
- 模板与判据变化时必须同步离线回放；实机素材用实时监控采集，留出集在判据冻结后采集。

## Evidence

- 原型：多锚点跨会话 44/49，原始帧约 6 ms；后台 OCR 时快路径 P95 16.5 ms；一次最小实机闭环到达选卡页后停止，未点击指令卡。
- 合并实现：感知单测 52 项、回放 118/118；留出集（冻结规则后采集）17 帧，票据口径首轮 15/17，两处问题已修复并转回归。

## Considered Options

- **同步全图 OCR**：单次秒级，无法满足战斗中的状态判定，否决。
- **全局图像最近邻**：跨会话原型仅 42.9%，否决。
- **多锚点 + 布局证据 + 后台按需 OCR**：采用。
