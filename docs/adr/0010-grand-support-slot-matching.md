# 冠位助战按三个礼装槽位筛选，未强制冠位时不排除冠位

Status: accepted（2026-11-28 与用户确认）

## Context

冠位助战的三个礼装位置不是三张可互换的普通概念礼装。第一槽是自由礼装，第二槽是该从者的牵绊礼装，第三槽是增加系礼装；第二槽还可把同一牵绊礼装的原本效果替换为 NP50%。只保存三个礼装 ID 无法表达用户需要的第一、第三槽多选，也无法区分第二槽的原本效果与 NP50%。

## Decision

第一、第三槽使用礼装候选集，槽位内任一礼装满足即可，不同槽位之间必须全部满足。第二槽使用“不限 / 原本效果 / NP50%”条件，不从礼装 ID 猜测效果模式。旧作业只有牵绊礼装 ID 时保留“必须装备该牵绊礼装”的限制，但两种效果均可。

未强制冠位表示普通助战和冠位助战都可选择，而不是必须选择普通助战。普通礼装条件对冠位助战核对第一槽，其余两槽不参与这类作业的选择。

清晰稳定但所需身份未识别的候选不选并继续搜索，不单独停止；模糊、遮挡、转场或关键区域缺失属于画面不可读，持续不可读才安全停止。两者不得合并成同一种失败。

## Consequences

- 作业格式需要为第一、第三槽增加候选集表达，并为第二槽单独保存效果模式；旧单值和旧牵绊礼装 ID 需要显式兼容。
- 严格冠位作业不能把普通助战作为识别失败后的降级选项。
- 本次只在助战列表筛选；队伍确认页的礼装轮播与多帧复核另行设计。

## Considered Options

- **继续把三槽都当作普通礼装 ID**：无法区分牵绊礼装的两种效果，也不能支持第一、第三槽多选，未采用。
- **未强制冠位时排除冠位助战**：会缩小可选范围，违背用户要求，未采用。
- **身份未识别就安全停止**：画面清晰但图库不认识对象时会频繁中断搜索，未采用；只有持续画面不可读才停止。
