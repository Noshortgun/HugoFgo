# AP 恢复采用用户白名单，默认仅允许青铜苹果

Status: accepted（2026-11-19 与用户确认，取代早先"绝不自动消耗苹果"的规则）

用户要求 AP 不足时自动补充体力。恢复道具是不可逆库存，因此不采用"全自动吃苹果"，也不采用"一律禁止"，而是用户白名单：4 种苹果与圣晶石共 5 种方式，由用户逐项勾选允许哪些；初始默认仅允许青铜苹果，圣晶石默认关闭且需显式勾选；选择持久化。

固定场数阶段可按白名单补足 AP；用户开启"清 AP"时，场数刷完后继续刷到当前剩余 AP 归零，此阶段不再使用任何恢复道具——否则会陷入"吃苹果→又有 AP→继续刷"的死循环。

每次消耗经后续画面确认成功后才写入日志并计入运行状态，运行面板可见"已用 N 个"；无法确认时安全停止且不计数。白名单为空时，AP 恢复页只停不点。

## Considered Options

- **一律禁止恢复**（早期规则）：与用户"刷满场数"的目标冲突。
- **无上限自动恢复**：可能一次耗尽长期积累的道具，不可逆。
