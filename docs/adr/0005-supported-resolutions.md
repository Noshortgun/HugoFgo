# 只支持精确 16:9 且不低于 1280×720 的横屏分辨率

Status: accepted（2026-11-20，用户明确确认）

坐标统一以 1280×720 为基准。网关只接受精确 16:9 且不低于 1280×720 的横屏分辨率，例如 1280×720、1600×900、1920×1080、2560×1440、3840×2160。

## Consequences

- `1366×768`、`1920×1088`、`2340×1080`、竖屏等宽高比或尺寸不符合要求的设备会被明确拒绝，不按近似比例盲点。
- 用户需要把模拟器调整为精确 16:9 横屏；错误信息必须给出这个操作建议。
- 未来若确有非 16:9 设备需求，先补真实截图与坐标验证，再扩展支持集，不靠放宽容差解决。

## Considered Options

- **允许 1% 宽高比容差**：可放行带系统栏的 1920×1088，但坐标会按含系统栏的整屏缩放，底部操作可能落进系统栏；与“不盲点”冲突。
- **支持任意分辨率线性缩放**：窄屏或超宽屏的水平/垂直比例不一致，点击位置会漂移，不能作为默认行为。
