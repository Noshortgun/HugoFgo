# 作业文件的读写由桌面壳负责，不再依赖 Vite 开发服务器

Status: accepted（2026-11-19；壳代码复用，新增作业与资源命令）

作业库目前通过 Vite 中间件的 `/api/jobs` 读写 `jobs/` 目录，打包成桌面应用后这条路径不存在。重构后由 Tauri 命令负责作业读写，前端通过统一接口调用；纯浏览器预览模式降级为只读演示，不保证保存。

理由：作业是产品的核心数据，它的持久化不能依赖开发期工具链。这也让执行器与 UI 读写同一份文件，避免两份作业定义漂移。

## Consequences

- 前端作业库接口需要抽象一层，浏览器预览下保存功能要明确提示不可用，而不是静默失败。
- `jobs/` 目录仍是唯一存储位置，作业格式 version 1 保持不变。
