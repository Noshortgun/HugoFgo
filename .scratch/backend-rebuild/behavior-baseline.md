## 3. 旧版明确不支持的能力（重写时不是缺陷）

- 任意作业的完整执行（只支持单一写死作业的每面首回合）
- 多回合动作序列、锁卡、通用宝具识别
- 非 1280×720 分辨率、非国区区服
- 从 UI 启动、实时状态推送、运行记录
- AP 恢复道具的可配置使用（旧版一律停止）

以上除"区服"与"锁卡/格式 v2"外，均属于本轮重写要补齐的能力。
