# 04: 作业编译为完整执行计划

**What to build:** 任意合法作业 JSON 都能编译成"面 → 回合 → 动作序列"的执行计划，覆盖多回合、技能目标、御主技能、换人、敌方目标切换与宝具卡序。作业里出现执行器不支持的能力时，在运行前就明确报错，而不是跑到一半乱点。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 现有示例作业编译出的每面动作序列与行为基线中记录的实测行为一致
- [ ] 多回合作业能编译出全部回合，不再只取每面首回合
- [ ] 换人、御主技能目标、宝具卡序位置在计划中表达完整
- [ ] 不支持的动作或字段在编译期报错，错误信息指明是哪一面哪一回合
- [ ] 非法作业（缺面、槽位越界、引用了空槽位）被拒绝并说明原因
- [ ] 编译结果可离线断言，不接触真实设备
- [ ] 作业 JSON Schema 作为契约单源，前端与执行器共用同一份校验规则，不各写一套
