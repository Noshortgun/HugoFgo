# 56: 冠位助战与三格冠位礼装识别

**Status:** ready-for-human

Source: 2026-11-24 编队能力审计。前端可以配置 `grandRequired`、`grandCe` 和 `grandCeIds`，执行器无法正确匹配。

## What to build

助战候选识别需要读取冠位助战身份，以及三个冠位礼装位置的条件与具体礼装。严格冠位助战只能选择同时满足全部已配置条件的候选，不能把普通助战当成冠位助战。

当前问题：

- `SupportCandidate` 没有冠位助战和三格冠位礼装数据。
- `support_matches` 的冠位条件永远无法被满足，严格冠位目标只能以找不到助战结束。
- 三格礼装不能只按名称模糊匹配，名称与 ID 都存在时必须核对 ID。

## Acceptance criteria

- [ ] 助战候选能区分普通助战与冠位助战。
- [ ] 三个冠位礼装位置分别核对已配置的条件和礼装；未配置的位置不限制。
- [ ] 普通助战、错误礼装和不完整条件均不会被误选为严格冠位助战。
- [ ] 冠位标记或礼装持续无法识别时安全停止，并给出独立失败原因，不按普通助战降级。
- [ ] 至少一条真实助战列表截图回放覆盖“正确候选”“普通候选排除”和“识别不确定停止”。
- [ ] `npm run verify` 全绿。

## Out of scope

- 不改变普通助战和任意助战的选择逻辑。
- 不新增冠位助战刷新策略。
- 不在前端增加新的冠位编辑功能。
