# 05C: 执行器回放验收

## Parent

#5

## What to build

交付新执行器的离线回放 harness：把 05A 的真实国服感知、05B 的状态机和 #3 的 `FakeDevice` 串起来，用现有截图复现完整闭环与异常分支。

本票只负责端到端验证与证据输出，不新增识别规则或状态机业务逻辑。

## Acceptance criteria

- [ ] 新回放入口跑通助战 → 队伍 → 战斗 → 结算 → 连续出击/完成，覆盖 loading 与过渡画面。
- [ ] 从战斗中途、结算页、助战页启动均可接续；unknown 停止并留存证据；误开界面（从者详情/冠位页）关闭返回；AP 恢复按 07 策略（默认青铜，白名单为空时停止）。
- [ ] 行为基线 B01–B23 中属于本范围的条目有新回放用例，断言动作序列、事件顺序与停止原因。
- [ ] 连续出击只在弹窗出现后点击，末场不多点；每个动作后都有重新识别。
- [ ] 新回放入口退出码 0；既有 `npm run replay` 36/36，构建通过。
