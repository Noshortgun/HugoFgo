# 54: 助战指令卡标签临界得分时确认唯一助战槽

Source: 2026-11-23 修复既有统一回放失败 `perception:live-obscured-support-card`。

## What to build

卡脸被技能文字遮挡时，助战标识得分可能落在兜底阈值（0.58）与确认阈值（0.70）之间。旧逻辑只在 SIFT 认不出从者时才用“唯一助战槽”兜底；如果 SIFT 仍能认出从者，这张卡会被归到同一从者的非助战槽位，实机上会把助战卡当成自己的卡。

新规则：只要标签得分达到兜底阈值、编队恰好只有一个助战槽且识别出的从者与该槽一致，就用该助战槽确认身份；SIFT 成功与否不再决定是否兜底。

## Acceptance criteria

- [ ] `captures/2026-11-23/key/live-card-support-obscured.png` 的卡4 识别为助战槽位。
- [ ] 同一帧里没有助战标识的卡5 仍归非助战槽位。
- [ ] 新增单元测试在 SIFT 成功时也覆盖该分支，不依赖本机是否存在 Atlas 指令卡素材。
- [ ] `npm run verify` 全绿；统一回放 232/232。

## Out of scope

- 不调整助战标签的 0.58 / 0.70 阈值。
- 不改变多助战槽编队下的兜底策略。
