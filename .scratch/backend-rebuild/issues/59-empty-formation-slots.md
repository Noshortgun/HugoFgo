# 59: 空白从者槽位的编队校验与执行行为

**Status:** ready-for-agent

Source: 2026-11-24 编队能力审计。前端允许空槽位，执行器的场上槽位、队伍核对和操作目标没有统一处理空白从者。

## What to build

明确并落实空白从者槽位规则：前三位必须完整，后三位允许空白。执行器不得把空槽位当成可上场从者、可换人对象或可指向目标。

当前问题：

- 执行器固定以 `[0, 1, 2]` 作为先发槽位。
- 队伍核对、换人、技能目标和选卡可能引用没有从者的槽位。
- 前端只显示空位，没有在启动前完整阻止不可执行引用。

## Acceptance criteria

- [ ] 前三号位存在空白从者时，启动前明确拒绝并定位槽位。
- [ ] 后三号位可以空白，队伍核对只处理实际存在的候补。
- [ ] 换人上场目标为空白槽位时，启动前拒绝。
- [ ] 技能、宝具、换人和敌方/己方目标不得指向不存在的从者槽位。
- [ ] 空槽位不会进入从者顺序、宝具卡序或指令卡身份映射。
- [ ] 新增作业往返、编译器和执行器测试；`npm run verify` 全绿。

## Out of scope

- 不改变游戏内编队或自动补位。
- 不实现任意助战；见票据 58。
- 不改变六槽位界面的视觉布局。
