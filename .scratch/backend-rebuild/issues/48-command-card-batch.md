# 48: 一次识别的三卡连击与有限恢复

## Parent

#49

## What to build

在卡面证据完整后，一次识别整手牌并计算三张卡的选择，按 200 ms 初始间隔连续提交，不再为每张普通卡重新截图、识别和稳定等待。整链提交后确认画面变化；异常时重新读取并最多恢复一次，无法确认则安全停止。

## Acceptance criteria

- [ ] 连击前必须确认五张普通卡完整展开，且作业要求的宝具卡可确认；证据不足时继续等待，不按时盲点。
- [ ] 正常路径复用同一手牌的身份与选择结果，以 200 ms 作为初始卡间间隔连续提交三卡，普通卡之间不重新识别整手牌。
- [ ] 200 ms 参数集中管理并可由实机证据调整；若漏卡，可评估 250/300 ms，不通过恢复逐卡完整识别解决。
- [ ] 三卡提交后以离开选卡页或进入已识别后续画面作为确认；2 秒仍停留时重新读取画面并最多恢复一次，仍无法确认则安全停止。
- [ ] 不直接重复整串点击；恢复后不得复用已经失效的选卡、宝具或遮挡状态。
- [ ] 宝具不可用等异常根据新画面处理，未知画面、意外弹窗和身份不确定仍安全停止。
- [ ] 动作日志能够计算卡间间隔、攻击到首卡耗时和恢复次数，并保持逐面逐回合动作审计可核对。
- [ ] 离线回放覆盖正常连击、卡面未展开、宝具未确认、提交停留、一次恢复成功、恢复失败和过期手牌失效。
- [ ] 与动作级确认共用同一状态机；统一回放与执行器测试通过，实机速度目标由后续验收票判定。
