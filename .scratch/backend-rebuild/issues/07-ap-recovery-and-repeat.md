# 07: AP 恢复策略、连续出击与运行设置

**What to build:** 用户能配置一次运行怎么刷：固定场数、AP 不足时允许用哪些恢复道具（默认仅赤铜苹果）、场数刷完后是否继续清空剩余 AP。执行器严格按这套策略执行，每次消耗都计数并显示。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 恢复方式为用户可选白名单（4 种苹果 + 圣晶石，名称以游戏内恢复页实测为准），初始默认仅允许赤铜苹果
- [ ] 用户选择持久化，下次启动保持
- [ ] AP 恢复页只使用白名单内的方式；白名单为空时恢复页即停止
- [ ] 固定场数阶段允许按白名单补足 AP；场数刷完且开启清 AP 时，继续刷到当前剩余 AP 归零，此阶段不再使用任何恢复道具
- [ ] 圣晶石只有用户显式勾选才允许，默认关闭
- [ ] 每次消耗恢复道具写入日志并计入运行状态，面板可见"已用 N 个"
- [ ] 回放覆盖：白名单内道具可用、非白名单道具不点、清 AP 阶段不吃苹果、AP 归零正常结束
