# 06: 补刀策略与选卡在执行器中生效

**What to build:** 作业里的补刀策略真正决定执行器的选卡行为：按从者优先级、卡色优先级与策略顺序选卡，支持全局配置与按面覆盖；一面未清场时按策略继续打。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 同一手牌在不同策略下产生不同选卡结果，回放可断言
- [ ] 按面覆盖生效：某面配置了策略就用该面的，否则用全局
- [ ] 同名同职阶的两个从者能按槽位区分，选卡不混淆
- [ ] 攻击动画中的文字不会被当成指令卡，只在指令卡区域选卡
- [ ] 手牌识别为空或不足三张时安全停止，不盲点
