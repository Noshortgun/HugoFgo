# 08: 桌面端一键运行与真实运行面板

**What to build:** 在桌面应用里选好设备与作业，点"开始运行"就真的启动执行器；运行面板显示真实的面、回合、当前动作、耗时与恢复道具消耗，停止按钮能立即终止执行器。演示数据全部移除。

**Blocked by:** 05, 07

**Status:** ready-for-agent

- [ ] 开始运行会启动执行器子进程并读取选中的作业，不再只是登记状态
- [ ] 运行面板的面/回合/动作/耗时/已用恢复道具数量来自执行器推送，不是写死的文案
- [ ] 运行设置（场数、恢复白名单、清 AP 开关）在 UI 可改并持久化
- [ ] 停止按钮立即终止执行器，设备上不再有点击发生；不提供暂停
- [ ] 同一时间只允许一个运行中的作业，重复启动给出提示
- [ ] 执行器异常退出时 UI 显示失败原因与日志位置
- [ ] 浏览器预览模式下运行按钮明确不可用，而不是点了没反应
