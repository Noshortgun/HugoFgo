# 03: 新建设备访问层

**What to build:** 新后端唯一的设备接口（截图、点击、滑动、分辨率）。实机走 adb，回放飞假设备，两者对上层完全同形。adb 路径、设备 serial、坐标基准都是配置项。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 接口同时有实机与假设备两个实现，上层代码不感知差异
- [ ] 1280×720 基准坐标由设备层换算到实际分辨率；不支持的分辨率明确报错而不是盲点
- [ ] adb 路径与设备 serial 可配置，缺失时给出可操作的中文错误提示
- [ ] 截图无效、adb 失败等错误统一抛出并带上下文，不被静默吞掉
- [ ] 用行为基线中的截图驱动假设备，验证接口能满足后续执行器的全部需要
- [ ] 设备枚举、设备信息、截图预览接入桌面壳，前端设备面板可用
- [ ] 设备配置包含区服（国服/日服/台服），区服属于设备而非作业；识别配置与图库按设备的区服加载
