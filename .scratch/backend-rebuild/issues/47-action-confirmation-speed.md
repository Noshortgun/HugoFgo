# 47: 战斗动作级确认与动画跳过

## Parent

#49

## What to build

将战斗内技能、切敌和攻击从统一稳定等待改为动作级确认。技能后主动跳过可跳过动画，以攻击按钮和战斗菜单恢复作为下一动作依据；定向技能保留目标面板证据，异常只能有限恢复。第三张卡后按频率上限跳过攻击动画。运行证据能够区分动作等待、实际点击和通道耗时，ADB 与后续 scrcpy 共用这套行为。

## Acceptance criteria

- [ ] 战斗内动作不再共用 0.5 秒稳定窗口；助战、AP、结算等战斗外流程行为不变。
- [ ] 无目标技能不再强制要求先观察到动画开始；技能后主动点击跳过区，只有攻击按钮和战斗菜单恢复后才执行下一动作。
- [ ] 定向技能仍确认目标面板出现与关闭；完全观察不到状态变化时最多基于新帧恢复一次，仍无法确认则安全停止。
- [ ] 第三张卡后每 1 秒最多点击一次战斗跳过区；选卡页残留时不点击，攻击按钮恢复或出现其他已识别页面后停止跳过。
- [ ] 未知画面、意外弹窗、控件或身份不确定仍禁止点击，固定延迟不得替代画面证据。
- [ ] 动作事件保留面、回合、坐标、原因和时间戳，并增加足以定位等待阶段的计时证据；现有运行历史与动作审计仍可用。
- [ ] 离线回放覆盖普通技能、定向技能、状态变化缺失、一次恢复、恢复失败、动画跳过频率、跨面/回合和意外弹窗。
- [ ] 统一回放与执行器测试通过；尚未进行实机验收时不得宣称稳定。
