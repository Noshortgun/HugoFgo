# 64: 计划外自动战斗、非阻塞告知与退场补位预览

**Status:** ready-for-agent
**Blocked by:** 59（空槽位不限制、两层选卡与一次性编队核对）、57（每场一次主动换人、退场补位与指定从者内部接替）

## Context

用户希望自动刷本省心，不因小的计划偏差直接停止。现有补刀只负责“计划基本正常但未清场”时选卡，不会主动使用技能和宝具；真正进入计划偏离时，前端的计划前排也没有推演自我退场后的自动补位，Chaldea 导入无法正确映射退场后的位置动作。

用户已确认：

- 计划偏离不是停止理由；原动作无法执行时，当前场进入与补刀分离的计划外自动战斗。
- 进入时必须告知用户，但提示不得暂停运行。
- 前端编辑时应根据 Atlas 效果推演自我退场，下一回合自动补上第一名替补。
- 不为作业新增退场字段；Chaldea 兼容沿用“动作记录 + 运行时实际结果”的表达。

详见 ADR-0008 和需求 F1.10、F1.11、F5.13–F5.15、F7.6。

## Goal

原计划失效时，用户能收到一次非阻塞告知，程序自动完成当前场并在下一场恢复作业；前端能正确预览退场补位，Chaldea 导入能按补位后位置映射动作。

## Constraints

- 计划外自动战斗只持续当前场（可跨该场的多个面），下一场恢复原始作业和初始编队。
- 补刀策略与计划外自动战斗分开实现，不能把补刀 `allowNp` 或固定宝具卡位直接复用到自动战斗。
- 空槽实际从者不主动释放技能，只自动使用宝具与普通卡。
- 用户不能为 C 编排技能、宝具、目标或卡序；不能因 C 实际在场而放开作业显式引用。
- 不新增退场字段，不按从者名字或 ID 直接认定必然退场。
- 提示不暂停执行、不要求确认、不自动切换用户所在页面；每次进入该模式告知一次。
- 画面、从者或安全操作目标无法确认时仍安全停止，不试探点击。
- 不改桌面历史页架构；只增加运行事件、状态与证据字段。

## Implementation notes

### 运行时

- 在每个计划动作前核对最小可执行条件：行动从者在场、所需目标在场、所需技能／宝具／换人控件确认可用。能执行就继续原作业。
- 不能执行时记录计划偏离事件，包含当前场／面／回合、原动作和原因，并进入计划外自动战斗。
- 自动战斗顺序：前排从左到右，每人一至三技能；己方目标选最左存活指定从者，无可用指定目标则跳过；敌人目标用当前选中敌人。技能后优先使用确认可用的宝具，指定从者宝具优先于 C 宝具；无可用宝具后按两层顺序选普通卡。
- C 只自动使用宝具与普通卡，不主动释放技能。
- 自动战斗不使用补刀 `allowNp` 和固定宝具卡位；显式作业宝具仍按既有规则。
- 进入模式时发出一次事件供 UI 弹出告知；事件同时进入运行时间线与摘要。下一场清除自动战斗状态。
- 中途启动无法还原换人／补位历史但能确认当前战斗画面时，也进入该模式而非直接停止。

### 前端计划前排

- 初始状态始终使用物理 0–5 六槽，不把空槽压缩掉。
- 按面／回合／动作顺序推演主动换人与自我退场；同一场跨面保持，下一场恢复初始编队。
- 依据 Atlas 技能／宝具函数识别退场预期，至少覆盖“对自身强制即死”和“赋予自身延迟即死”，不得只写死阿拉什或哈贝喵名字。
- 当前回合仍显示即将退场的从者；从下一回合起移除，并由当前候补队列首位补入。第一名候补是空槽时显示“可能为任意从者或为空”的占位，不能提前把后续指定替补挪上来。
- 空槽占位不能提供技能、宝具或目标按钮。
- 删除退场动作或调整顺序后，整个计划前排与候补队列纯重算；删除动作只表示作业不再触发退场，不代表实机复活。下一场副本才恢复初始编队。
- 技能与宝具选择列表包含全部指定从者，并标注“当前计划前排”或“后续上场后执行”；C 不出现在列表中。
- 资源侧需要把识别退场所需的函数字段加入前端可加载的 Atlas 索引；不得每次从大型原始 JSON 全量读取。

### Chaldea 导入

- 复用同一套计划前排推演，把 Chaldea 的当前位置动作映射回原始指定槽位。
- 资料不足无法可靠判断退场或补位时不猜测，保留作业并显示导入后检查提示。
- 新旧 Chaldea 数据都缺少 ID 时，可按名称与职阶尽力匹配；仍无法确认时不得伪造补位结果。

### 告知 UI

- 在应用根部增加全局非阻塞提示；即使用户位于编队或历史页也能看到。
- 内容包含触发原因、当前场自动、下一场恢复作业，以及“停止运行”“知道了”。
- “知道了”只关闭提示；运行页持续显示“计划外自动战斗中”和原因，事件时间线永久保留。
- 同一场只提示一次，不自动跳转页面。

## Steps

1. 实现最小动作可执行检查与计划偏离事件。
2. 实现计划外自动战斗的技能、目标、宝具与普通卡顺序，并补单测。
3. 增加全局非阻塞提示和运行状态／事件记录。
4. 扩展前端 Atlas 索引与计划前排推演，支持退场、补位、删除重算和候选标注。
5. 让 Chaldea 导入复用计划前排推演，补新旧数据用例。
6. 补运行事件、前端构建、转换器与回放验证。

## Acceptance criteria

- [ ] 下一个计划动作可执行时继续原作业，不因历史偏差提前进入自动战斗。
- [ ] 行动从者、目标或控件不可用时记录计划偏离并进入计划外自动战斗，不静默跳过动作。
- [ ] 自动战斗按已确认的技能顺序、己方目标、宝具与普通卡规则执行；C 不放技能。
- [ ] 自动战斗不沿用补刀 `allowNp` 或固定宝具卡位，下一场恢复原作业。
- [ ] 进入自动战斗有全局非阻塞提示，不暂停执行；运行状态、时间线和摘要保留原因。
- [ ] 前端能根据 Atlas 识别阿拉什宝具与哈贝喵技能等退场，下一回合由候补首位补位；删除动作后重算，下一场才恢复初始编队。
- [ ] 空槽候补显示为不可编排占位，不把后续指定替补提前补上，也不允许给 C 添加动作。
- [ ] Chaldea 导入按补位后的位置映射动作；资料不足时提示检查而不是猜测。
- [ ] 中途启动能确认战斗但无法还原历史时进入自动战斗；画面不明时仍安全停止。
- [ ] `npm run verify` 全绿。
