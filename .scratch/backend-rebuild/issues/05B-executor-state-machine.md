# 05B: 执行器状态机

## Parent

#5

## What to build

交付执行器核心：消费 #4 的 `ExecutionPlan` 与 05A 的 `Observation`，通过 #3 的 `Device` 接口推进助战选择、队伍确认、战斗、选卡、结算，并输出事件与安全停止结果。运行进度与画面状态分离，只能由已确认的画面证据推进。

本票不负责真实图像识别规则，也不搭建完整截图回放；测试使用脚本化 `Observation` 与 `FakeDevice`。完整补刀策略、AP 恢复白名单与清 AP 阶段分别留给 #6、#7。真实感知尚未提供的助战身份与指令卡身份必须登记为 05C 前的明确缺口，不用显示名称伪装已支持。

## Contract additions

- `ExecutionPlan` 保留执行所需的编队槽位、从者标识、助战标记、强制助战、冠位要求及概念礼装条件；执行器不重新解析作业 JSON，作业格式 v1 不变。
- `Observation` 为助战候选和指令卡提供结构化身份，不把槽位、卡色或助战条件编码进控件显示名称。本票只要求契约与脚本化观察可用。
- 连续出击场数属于运行参数，默认 1，不属于作业。
- `kind: "attack"` 表示宝具需求，不在战斗页触发点击；在选卡页与 `npPositions` 合并后统一安排宝具卡序，再处理普通指令卡。冲突卡序在编译期诊断。

## Confirmed behavior

- 动作前检查可操作性；同一目标在相同画面、变体和覆盖层下连续稳定 0.5 秒才点击。坐标允许小幅识别抖动，相关变化重新计时。阈值集中在配置中，后续实机标定。
- 点击不直接推进运行进度；动作后重新截图识别，符合预期结果才推进。动作确认、旧帧残留、loading 与 unknown 等待上限初值 30 秒，单场战斗上限初值 300 秒。
- 第三张指令卡提交后立即停止本轮输入并等待攻击结束，不寻找额外确认按钮。
- `unknown` 不使用固定坐标或试探按钮。保留行为基线 B02/B19：已确认 drops 或 team 时才允许各自的既有坐标回退，点击后仍重新识别。
- 新启动能从 support、team、result、drops 及可确认进度的战斗边界接续。无法判断当前回合已执行动作或选卡进度时安全停止，不重复放技能。
- `verify` 发卡不匹配时安全停止；`prefer` 仅在优先卡完整可匹配时执行，否则报告需要补刀策略。`strategy` 或选卡信息不足时，在运行前明确报告当前不支持，不随意补三张卡。因此现有《娄希、娄希、奥伯龙》作业需等 #6 才能完整运行。
- 动作严格按当前 `ExecutionPlan` 执行：有 `orderChange` 才换人，有 `master` 就按技能编号和目标执行。旧描述中的固定换人与“不使用御主二技能”不再作为规则。
- 固定场数连续出击只在弹窗出现后点击，末场不点。本票遇到 ap_recovery 安全停止，不使用恢复道具。
- 从者详情、意外冠位页等误开界面按已识别控件关闭返回；没有已确认恢复路径时安全停止。

## Events and evidence

事件至少包含 `state_changed`、`action`、`wave_started`、`turn_started`、`warning`、`finished`、`failed`、`stopped`。动作事件带基准坐标与原因，停止事件带原因与证据位置。测试使用内存事件出口，文件输出使用 JSON Lines；生产运行默认在 `logs/farm/<时间戳>/` 保存事件、最终结果与安全停止截图，测试可显式关闭文件输出，不提前实现桌面历史页。`RunControl.stop()` 在动作边界生效，停止后不再有点击。

unknown 停止证据包含最终截图、观察结果、近期动作、运行进度、重试次数、停止原因及设备与作业信息。后续新增返回正常流程的规则前必须先补回放用例。

## Acceptance criteria

- [x] `run(plan, device, perception, events)` 按基页、变体与覆盖层推进，不从固定线性路径盲跑。
- [x] 稳定确认、动作后确认、第三张卡停止输入、超时与安全停止都有场景测试。
- [x] 助战、队伍、多面多回合、技能目标、御主技能、换人、宝具卡序、普通指令卡、结算和固定场数连续出击按作业执行。
- [x] 已知画面的有限回退、可确认进度接续和无法确认时停止都有回归用例。
- [x] 事件、坐标、运行进度、停止原因和证据文件可通过公开接口验证。
- [x] 使用脚本化 `Observation` 与 `FakeDevice` 验证动作、事件和停止顺序；既有感知与旧原型回放保持通过。
- [x] 实机短链路验证技能 → 攻击 → 选卡页安全决策。完整三卡实机与真实两场连刷在 #6 后验收；未完成前不得宣称稳定。
