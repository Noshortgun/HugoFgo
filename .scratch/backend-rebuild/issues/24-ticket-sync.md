# 24: GitHub 票据同步与本地漂移检查

## What to build

让 GitHub Issue 成为唯一权威内容，同时保留可审查的本地发布源。提供同步与漂移检查：从 GitHub 获取每张票的当前正文，和本地准备发布的内容比较；发布前必须看到差异。每张票只保留一个可手工编辑的文件，不再靠两个同名草稿保持同步。

## Acceptance criteria

- [ ] 能按票据编号从 GitHub 拉取正文、标签与状态到受控本地副本。
- [ ] 发布前显示逐票差异，并区分新增、修改、无变化。
- [ ] 本地副本与远端不一致时，发布检查返回非零并指出具体票据。
- [ ] 每张票只有一个明确的手工编辑源；重复编号或遗留双份文件会被报告。
- [ ] 不允许误改父票据或已关闭票据；提供明确保护或失败提示。
- [ ] 现有票据完成一次迁移后，新会话能从本地源判断该发布什么。

## Blocked by

None (can start immediately)
