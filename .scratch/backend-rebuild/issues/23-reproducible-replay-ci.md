# 23: 可移植回放环境与 CI 护栏

## What to build

让回放在干净环境和 CI 中可复现。固定 Python 依赖版本，统一安装方式；回放入口在启动前验证真实依赖可导入，缺依赖时立即停止并给出可复制命令。CI 自动执行安装、前端构建和统一回放，保证当前 36/36 不依赖某一台电脑上的隐藏环境。

## Acceptance criteria

- [ ] Python 依赖有明确的版本清单或锁文件，干净环境按文档一次安装成功。
- [ ] 回放入口在运行用例前检查真实依赖导入；失败时不产生部分回放结果。
- [ ] 缺依赖提示给出单一、可复制的安装步骤，不要求使用者猜解释器或包名。
- [ ] CI 在拉取请求和主分支推送时执行依赖安装、构建和统一回放。
- [ ] 干净克隆按 README 执行同一命令可得到 36/36；CI 与本地入口一致。
- [ ] CI 失败能定位到构建、依赖或具体回放用例，而不是只给一个总失败。

## Blocked by

None (can start immediately)
