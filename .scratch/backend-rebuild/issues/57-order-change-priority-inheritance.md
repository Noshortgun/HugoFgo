# 57: 换人后从者接替原位置选卡优先级

**Status:** ready-for-agent

Source: 2026-11-24 用户确认。换人本身可执行，但选卡策略仍按原始编队槽位排序。

## What to build

换人确认后，上场从者接替下场从者在选卡策略中的优先级位置。此规则影响普通指令卡选择，不改变作业文件格式。

当前问题：

- 换人只更新场上 `active_slots`。
- `select_cards` 每次仍按作业原始槽位生成从者优先级。
- 上场后排从者通常排在剩余原前排之后，与场上位置直觉不一致。

## Acceptance criteria

- [ ] 换人确认后，上场从者继承下场从者的优先级位置。
- [ ] 上场从者原本已在顺序中时去重，只保留接替后的位置。
- [ ] 后续换人继续按当前位置接替，不累积重复项。
- [ ] 每场战斗开始恢复到作业原始从者顺序。
- [ ] 全局策略和按面策略都遵守同一接替规则。
- [ ] 已在场从者、宝具卡序和普通指令卡身份不受影响。
- [ ] 新增策略单测和换人后选卡回放；`npm run verify` 全绿。

## Out of scope

- 不修改作业 Schema。
- 不改变换人的点击流程。
- 不改变宝具固定卡位的占位规则。
