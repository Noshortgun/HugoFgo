# 09: 作业存储与资源任务迁移到桌面壳

**What to build:** 打包后的桌面应用里，作业库的保存、列表、打开，以及资源的检查更新、增量更新、校验、完整校准都能用，不依赖 Vite 开发服务器。作业格式与存储目录不变，执行器与 UI 读写同一份作业文件；资源按区服分目录缓存。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 桌面版中保存作业后能在列表看到并重新打开，内容完整
- [ ] 打包后的应用中作业读写可用，不需要起开发服务器
- [ ] 作业文件名清洗与路径逃逸防护保留
- [ ] 资源的检查更新、增量更新、校验、完整校准由壳触发，前端能展示进度与结果
- [ ] 图库与资源清单按区服分目录、各自独立，切换区服不需要重下已有区服
- [ ] 资源管线的 SHA-256 校验与原子写入行为保持不变
- [ ] 浏览器预览模式下保存与资源更新明确提示不可用
- [ ] 开发服务器的 jobs 与 resources API 移除，前端不再依赖它们
