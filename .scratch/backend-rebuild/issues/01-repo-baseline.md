# 01: 建立可回滚的工程基线

**What to build:** 项目进入版本控制，并且任何人（或任何新会话）能用一条命令跑通全部离线回放。之后所有重写工作都在这个基线上进行。

**Blocked by:** None (can start immediately)

**Status:** in-progress（除首次提交外均完成，待 git 署名）

- [ ] 初始化 git 仓库并完成首次提交，提交前确认忽略规则覆盖依赖目录、构建产物、运行日志与临时截图
- [ ] 确定 `captures/` 素材的版本策略（真实故障截图必须入库，大批量调试图不入库），并写进忽略规则
- [ ] `.scratch/` 的 spec 与票据入库，作为项目管理数据
- [ ] 提供一条命令跑全部回放（例如 `npm run replay`），失败时退出码非 0
- [ ] 在项目文档中写明环境准备与回放命令，新会话无需翻 HANDOFF 即可上手
