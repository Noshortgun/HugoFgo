# 05: 画面状态机执行器

**What to build:** 新的执行循环由画面状态驱动：识别状态 → 执行该状态允许的动作 → 重新识别确认。能完成"助战选择 → 队伍确认 → 战斗 → 结算 → 连续出击"的完整闭环，遇到未知画面安全停止；从任意已知画面启动都能接续。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 完整闭环在回放中跑通，包含加载与过渡画面
- [ ] 每个动作后都重新识别确认，不存在序列内盲点
- [ ] unknown、从者详情、意外冠位页触发安全停止并保存截图与日志
- [ ] 从战斗中途、结算页、助战页启动都能接续，不要求固定起始页
- [ ] 行为基线清单中的每一条已验证行为都有对应回放用例并通过
- [ ] 连续出击只在弹窗出现后点击，末轮不点击
- [ ] 运行过程持续输出结构化状态（面、回合、当前动作），供桌面端消费
- [ ] 识别配置按设备的区服加载，首期实装国服
