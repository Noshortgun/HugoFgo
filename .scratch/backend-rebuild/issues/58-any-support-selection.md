# 58: 任意助战的选择、身份绑定与队伍核对

**Status:** ready-for-human

Source: 2026-11-24 编队能力审计。前端允许标记不指定从者、概念礼装和职阶的任意助战，执行器没有完整的身份绑定流程。

## What to build

“任意助战”表示不设置从者、职阶和礼装条件，但执行器仍必须把实际选中的候选绑定为唯一助战槽，供队伍核对、指令卡识别和换人使用。

当前问题：

- 无 `supportRequired` 条件时直接选择第一个识别的候选，没有记录实际身份。
- 队伍核对仍按作业内空的助战从者 ID 比较，可能把正确队伍判成不匹配。
- 指令卡识别不知道实际助战从者时，该助战卡无法参与选卡。

## Acceptance criteria

- [ ] 任意助战在没有严格条件时选择第一个稳定、可操作的候选；不足以稳定确认时安全停止。
- [ ] 选定后记录实际从者 ID、职阶和概念礼装，并绑定到唯一助战槽。
- [ ] 队伍页按实际绑定身份核对，不按作业内空值核对。
- [ ] 助战指令卡按实际绑定身份参与普通选卡。
- [ ] 编队存在两个或更多任意助战槽时在启动前拒绝。
- [ ] 新增真实截图回放覆盖选择、队伍核对和助战卡身份；`npm run verify` 全绿。

## Out of scope

- 不实现冠位助战条件；见票据 56。
- 不调整严格助战的搜索与刷新规则。
- 不改变任意助战的默认刷新次数。
