# 22: 工程预检与实机操作安全门

## What to build

提供一条可在任何实施或实机会话前运行的只读预检命令，让人和 agent 都能判断当前环境是否适合继续。命令需要清楚报告当前工作分支、与远端的领先/落后关系、已跟踪文件是否有未提交改动、Python 回放依赖是否存在、adb 设备与分辨率是否可用，以及是否有 BBChannel 一类外部自动化进程正在运行。

预检本身不修改文件、不操作模拟器。实机输入必须由显式参数或交互确认开启；默认只读。危险状态使用非零退出码，并给出下一条可执行命令。

## Acceptance criteria

- [ ] 预检显示当前分支、与远端的领先/落后数量、已跟踪文件的未提交状态。
- [ ] 在原型分支或其他非施工分支准备实施时给出明确警告；允许用户显式确认后继续。
- [ ] 检查回放所需的 Python 解释器和真实依赖，而非只检查 Python 是否存在；失败信息可直接执行修复。
- [ ] 检查 adb 设备、连接状态和支持的分辨率。
- [ ] 检测外部自动化进程并明确警告，避免多个程序同时控制模拟器。
- [ ] 默认完全只读；任何实机点击必须显式开启，未开启时不会发送输入。
- [ ] 健康环境返回 0，存在阻断项返回非零；输出可被下一次 agent 会话直接读懂。

## Blocked by

None (can start immediately)
